# MyPerro Competitive Review — 10 Aug 2026

Current public products reviewed:

- [ComNyang](https://comnyang.com/en): input reactions, productivity, AI-agent states,
  pattern customization, and peek mode on Windows/macOS.
- [Bongo Cat Next](https://github.com/liwenka1/bongo-cat-next): Live2D-style pets,
  right-click controls, and Windows/macOS/Linux coverage.
- [VPet Simulator](https://store.steampowered.com/app/1920960/VPet/): care interactions,
  open source code, and Steam Workshop content.
- [Deskie update](https://steamdb.info/patchnotes/23253452/): custom uploads,
  AI-generated animation sets, stories, and conversational pets.

## Position

| Area | MyPerro | Competitive position |
|---|---|---|
| Reactive desktop motion | Cursor, drag, shake, pet, type, overheat, scroll, reminders, AI states | Strong breadth; commercial transition polish still trails ComNyang |
| Feature visibility | Gear entry, complete animation tour, live care dock, tray previews | Leading discoverability |
| Virtual-pet care | Persistent food, water, happiness, energy, requests, rest | Stronger than mascot-only products |
| Characters | Nine premium dog/cat companions | Strong built-in breadth |
| Productivity | Pomodoro, stretch/water/message reminders, pinned note | Strong |
| Desktop presence | 4 sizes, opacity, always-on-top, peek, drag, wander | Competitive after current pass |
| Privacy | Local activity counts only; no keycodes or telemetry | Leading and verifiable |
| Platform reach | Windows/macOS plus Linux X11/XWayland build path | Broader than ComNyang; native Wayland remains experimental |
| Personal creation | Presets, colours, markings | Behind Deskie AI creation and VPet Workshop |
| World interaction | Wander and edge peek | Behind products that perch on arbitrary app windows |
| Social / voice / chat | Not included | Behind conversational/voiced pets |
| Community ecosystem | Open source, but no pack browser/workshop | Major remaining gap |

## Recommended next investments

1. A documented third-party companion-pack format and in-app pack importer.
2. OS-specific active-window geometry so pets can perch on real window edges.
3. Optional local conversational personality, disabled by default for privacy.
4. Hardware QA matrix for macOS, Windows scaling, Linux X11, GNOME Wayland,
   KDE Wayland, and NVIDIA WebKitGTK.

MyPerro is now a strong open-source release candidate rather than a prototype.
Its next leap is professional frame-by-frame animation, an ecosystem, and deeper
desktop physics—not another settings page.
